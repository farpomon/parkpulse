# Wait Less, Ride More — Disney World Line-Skipping Guide

A single-page, self-contained guide to skipping lines at Walt Disney World in 2026:
what replaced FastPass, what the Lightning Lane options cost, which rides to book
first in each park, and the times of day when standby waits actually drop.

## Viewing

Open `index.html` in any browser — no build step, no dependencies.

## Contents

- **FastPass → Lightning Lane**: FastPass/FastPass+/MaxPass were retired in 2021;
  the guide covers the current Multi Pass, Single Pass, and Premier Pass options
  with 2026 price ranges.
- **Booking windows**: 7 days out for Disney resort guests, 3 days for everyone
  else, both at 7:00 AM ET.
- **Park-by-park priorities**: which attractions to book first (and which are
  fine in standby) at Magic Kingdom, Hollywood Studios, EPCOT, and Animal Kingdom.
- **Wait-time patterns**: rope drop and the final operating hour are the low
  points; 11 AM–4 PM is the peak; parade/fireworks windows cut waits 30–50%.
